# SOC Analyst Level 1 – Learning Documentation

## About This Project

This repository is a learning-focused documentation project covering the fundamentals of Security Operations Center (SOC) operations.

It includes key cybersecurity concepts, SOC team structure, security tools, log analysis, threat detection, incident response, and human-centered security.

The objective is to build a strong foundation in SOC operations and develop the knowledge required for an entry-level SOC Analyst role.

This documentation represents my ongoing learning journey. Practical labs, investigations, and hands-on projects will be added as I progress.

## Learning Goals

- Understand SOC operations and workflows.
- Learn SIEM, EDR, XDR, IDS, IPS, and SOAR concepts.
- Understand security logs and alert investigation.
- Develop incident detection and response knowledge.
- Build practical Blue Team and SOC Analyst skills.
